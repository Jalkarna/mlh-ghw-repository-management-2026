# Mergington High School Security Policy

## Reporting a vulnerability

Report vulnerabilities privately using this repository's **Security → Report a
vulnerability** form. Include a description, steps to reproduce, likely impact,
and any suggested fix. Do not publish vulnerability details in a public issue
or include private student information in the report.

## Handling reports

The maintainer will triage the report, coordinate any fix in private, and arrange
disclosure after the issue has been addressed. In the exercise's school scenario,
urgent issues affecting student data receive priority.

## Thank you

Responsible disclosure helps protect the school community and gives maintainers
time to address problems before details become public.
