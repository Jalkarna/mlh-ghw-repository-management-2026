# Contributing to the Mergington High Activities Website

Thank you for helping improve the school's activities website. Bug fixes,
club activities, and ideas for new features are welcome.

## Development setup

1. Clone the repository and create a Python virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Run the development server with `python src/app.py`.
4. Visit `http://localhost:8000` and try the included sample activities.

## Making changes

1. Create a descriptive branch, such as `fix-chess-signup`.
2. Make and check your changes locally using sample student data.
3. Push the branch and open a pull request with a clear description.
4. Address review feedback before merging. The main branch requires a PR.

## Code style

Follow PEP 8 for Python, use descriptive names, and explain non-obvious logic.
Keep local credentials, environments, and editor settings out of commits.

## Getting help

Check existing issues before opening a new one. Include reproduction steps,
expected behavior, and actual behavior when reporting a bug. In the training
scenario, IT Club office hours take place Thursdays at lunch in Room 203.
